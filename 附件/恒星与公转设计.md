# 恒星与公转候选

状态：设计稿，未写入正文。恒星参数是建议值，不是已确认设定。

## 约束

- 主行星覆盖热带、温带和寒带。
- 天堂能主动改变主行星轴倾角，并增减入射光照；具体工程机制可换。
- 怪动植物空载约 20 kg，在 60 km 巡航；背负时可以降低高度。
- 尽量保留现有行星、大气、羽翼和储能参数。

本稿不改动行星半径 15000 km、重力 20 m/s²、自转角速度对应的 24 h 周期、
当前轴倾角 23.44°、海平面气压 101300 Pa，以及大气模型的现有组分和温度剖面。
组分与温度剖面的物理问题仍需核对；“沿用计算”不代表已经证明它们能长期自然维持。

## 恒星候选

选近太阳的单颗恒星作基线，预计属于 G2 V 附近。现有光谱模型已经使用 5772 K，
因此这组候选对现有受光、光合和视觉计算的牵动较小。

| 量 | 候选值 |
|---|---:|
| 质量 | 1.9885×10³⁰ kg，约 1 个太阳质量 |
| 半径 | 6.957×10⁸ m |
| 有效温度 | 5772 K |
| 光度 | 3.828×10²⁶ W，由半径与温度计算 |
| 黑体波长谱峰值 | 502 nm |
| 多星结构 | 暂不加入伴星 |

质量是候选输入；光度使用 L=4πR²σT⁴ 求出。还没有用恒星演化轨迹联合验证
质量、半径、温度、年龄和金属丰度，故不另行指定精确年龄或寿命。

黑体谱只作连续谱近似。紫外、极紫外、耀斑和活动周期不能由 5772 K 单独确定，
也不能据此宣布臭氧、氨寿命及平流层温度已得到验证。外部资料检索当前失败，
本稿未完成观测恒星或恒星演化模型的独立比对。

## 公转候选

近圆轨道让季节主要由轴倾角产生。取偏心率 0.01，以时间平均辐照度 1360 W/m²
反求半长轴，不强行指定一年恰为地球年。

| 量 | 复算值 |
|---|---:|
| 偏心率 | 0.01，候选输入 |
| 半长轴 | 1.00045 AU |
| 公转周期 | 365.49 个 86400 s 日 |
| 近日点 | 0.99045 AU |
| 远日点 | 1.01046 AU |
| 时间平均辐照度 | 1360 W/m² |
| 近日点辐照度 | 1387.54 W/m² |
| 远日点辐照度 | 1333.14 W/m² |
| 恒星视直径，半长轴处 | 0.5327° |
| 平太阳日 | 24.0658 h，约 24 h 3 min 57 s |

采用的关系：

- 平均辐照 F=L/(4πa²√(1-e²))。
- 公转周期 P=2π√(a³/(G(M恒星+M行星)))。
- 平太阳日取顺行自转，1/P太阳日=1/P自转−1/P公转。

现有“24 h”在程序中作为恒星日使用。本稿沿用该角速度，不直接把它重解释为
24 h 太阳日。恒星年不应直接称为 365.49 个本地太阳日。

## 气候约束

维持现有平均入射能量，为保留飞行环境提供连续的起点；不保证大气会自行形成
现有温度剖面。恒星与轨道不能独立决定赤道、极点温度。

现有纬温曲线 300−60sin⁴φ 可以暂作目标场，其面积平均是 288 K。
在反照率 0.3 下，1360 W/m² 对应有效温度约 254.53 K。
两者之差约 33.47 K 只是诊断量，不能替代温室和热输送计算。

要验证热带至寒带同时存在，还需闭合水汽、云、冰雪反照率、海陆蓄热和纬向热输送。
现有月降水归一化、距海距离、季节温差及气候分类错误应先修正。
在这些环节完成前，不公布新的大陆气候表或天堂调温矩阵。

## 天堂调控的接口

近日点希尔半径约 3.325×10⁶ km；天堂现有半长轴约为其 6.89%。
这是尺度检查，不是完整的长期稳定性结论。

- 减光：重新计算含辐射压力的平衡位置、遮挡几何、热负荷和站控。
  不把原来的经典 L1 位置直接当成轻薄帆的工作位置。
- 增光：另设可行光路和收光面积，不能沿用原来的前向反射近似。
- 调倾角：区分自转轴进动与轴倾角变化，计算力矩和角动量交换。
  不把“天堂轨道面转 10°”直接换算成“主行星轴倾角转 10°”。

这些能力是保留的设计要求，工程实现、可达幅度、响应时间和工质循环尚未验证。

## 60 km 空载巡航

以下只检验旧大气与旧阻力模型的内部关系，不靠调整恒星掩盖飞行缺口。

| 量 | 赤道上空 | 极点上空 |
|---|---:|---:|
| 温度 | 240.24 K | 240.24 K |
| 气压 | 204.36 Pa | 191.10 Pa |
| 氧分压 | 40.91 Pa | 38.26 Pa |
| 空气密度 | 0.001086 kg/m³ | 0.001016 kg/m³ |
| 声速 | 543.93 m/s | 543.93 m/s |
| 失速速度 | 429.07 m/s | 443.70 m/s |
| 旧极曲线最小功率速度 | 456.52 m/s | 472.09 m/s |
| 对应马赫数 | 0.839 | 0.868 |
| 最小机械功率 | 3.101 kW | 3.207 kW |
| 总效率 0.85 时的储能输出 | 3.648 kW | 3.772 kW |
| 总效率 0.70 时的储能输出 | 4.430 kW | 4.581 kW |

总效率是储能到有效推进机械功的假设，0.70 和 0.85 仅作敏感性试算。
尚未计入跨声速波阻、辅助负载、呼吸及热管理，也未把光合计为可用供能。
这里的机械功率相当于旧脚本把推进效率取为 1 的输入功率，不能与生化分解功率混为一谈。

现有 3 kW 分解功率不能单独支持上述结果。氧分压也远低于原来 20 km 的呼吸设计点，
必须验证摄氧、储氧或其他供能路径。仅把旧图顶棚从 48 km 改成 60 km 不构成修复。
若行星和大气不变，优先检查生物侧的供能、阻力、翼面积和高空呼吸；具体修改待决定。
